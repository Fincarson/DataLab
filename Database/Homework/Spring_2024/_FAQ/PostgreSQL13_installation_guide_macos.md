# PostgreSQL 13 安裝教學 - MacOS

## 下載 PostgreSQL 13

* 下載： [https://postgresapp.com/](https://postgresapp.com/)
<div>
<img src="https://i.imgur.com/qRnBPCr.png" width="700">
</div>

* 將 Postgres 拖曳到應用程式裡。

    <div>
    <img src="https://i.imgur.com/FT5RRg1.gif" width="500">
    </div>

* 在應用程式中找到 Postgres 並開啟。
    <div>
    <img src="https://i.imgur.com/mVwKYDI.jpg" width="700" >
    </div>

<div>
<img src="https://i.imgur.com/NlE8pWM.png" width="500" >
</div>

* 打開後會看到 PostgreSQL 的 server
<div>
<img src="https://i.imgur.com/4FaqpSS.png" width="700">
</div>

* 可以從 Server Setting 中更改 server name 跟 port，也可以看到我們的資料從放的地方。
<div>
<img src="https://i.imgur.com/JsjtqjP.png" width="700">
</div>


* 點 “Initialize” server 就會 create 一些空的 DB，下圖為 initial 後的結果，如果你的 server 裡已經有 DB 可以忽略這個步驟。
<div>
<img src="https://i.imgur.com/C491Dqd.png" width="700">
</div>

* 點選想要使用的 DB，Postgres 就會幫我們連到該 DB，我們就可以開始進行操作了!
<div>
<img src="https://i.imgur.com/qklRTbF.png" width="700">
</div>
